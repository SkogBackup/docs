## Directory Purposes

**agents/**
- Purpose: AI agent personalities and persistent memory
- Contains: Profile.md, memory-blocks/, journal/, core/ directories
- Key files: `*/profile.md` (agent identity)
- Structure: claude/ (75+ journal entries), dot/ (12 memory blocks), goose/ (13 memory blocks)

**prompts/**
- Purpose: Reusable LLM prompt templates
- Contains: YAML-fronted markdown prompts
- Key files: `README.md` (index), `lore/entry-generation.md`, `personas/trait-generation.md`
- Structure: Organized by use case (lore, personas, guides)

**skogix/**
- Purpose: Human user context and notation system
- Contains: User preferences, formal notation, definitions
- Key files: `notation.md` (15KB formal system), `user.md` (communication style), `definitions.md`

**lore/**
- Purpose: Lore/mythology generation system documentation
- Contains: System architecture, pipeline docs
- Key files: `README.md` (35KB comprehensive docs)

**tools/**
- Purpose: External tool documentation
- Contains: argc framework docs, GitHub CLI docs
- Key files: `argc/SKILL.md`, `argc/reference.md`, `gh/filtering.md`
- Subdirectories: `argc/src/` (symlinks to source)

**governance/**
- Purpose: Project evolution and decision history
- Contains: Phase documents, library session records
- Key files: `phases/skogai-0.1-dictator.md`, `library-sessions/library-session-001.md`

**.research/**
- Purpose: Research notes and analysis
- Contains: Implementation decisions, system analysis
- Key files: `notation-systems-analysis.md`, `ollama-integration.md`

**todo/**
- Purpose: Archived v1.0 documentation reference
- Contains: Legacy interfaces, tools, prompts
- Key files: `CLAUDE.md`, `README.md`
- Note: Marked as "worktree `docs-fix`"

## Naming Conventions

**Files:**
- kebab-case for regular documents: `entry-generation.md`
- Date-prefix for journals: `2025-05-21-skogai-notation.md`
- UPPERCASE for special files: `CLAUDE.md`, `README.md`, `SKILL.md`
- Numbered memory blocks: `*-memory-block-01-*.md`

**Directories:**
- lowercase with hyphens: `memory-blocks/`, `library-sessions/`
- Plural for collections: `agents/`, `prompts/`, `tools/`

**Special Patterns:**
- `CLAUDE.md` - AI instruction files (per directory)
- `README.md` - Directory index/overview
- `profile.md` - Agent identity definition

## Where to Add New Code

**New Prompt:**
- Location: `prompts/{category}/`
- Tests: N/A (manual validation)
- Index: Update `prompts/README.md`

**New Agent Memory:**
- Location: `agents/{agent}/memory-blocks/`
- Naming: `{agent}-memory-block-{NN}-{title}.md`

**New Journal Entry:**
- Location: `agents/{agent}/journal/`
- Naming: `YYYY-MM-DD-{topic}.md`

**New Tool Documentation:**
- Location: `tools/{tool}/`
- Required: README.md, relevant guides

**Research Document:**
- Location: `.research/`
- Naming: `{topic}-analysis.md` or `{topic}-research.md`
