# Coding Conventions

**Analysis Date:** 2026-01-09

## Naming Patterns

**Files:**
- kebab-case for all documents: `entry-generation.md`, `trait-generation.md`
- Date-prefix for journals: `2025-05-21-skogai-notation.md`
- UPPERCASE for special files: `CLAUDE.md`, `README.md`, `SKILL.md`
- Numbered sequences: `*-memory-block-01-*.md` through `*-memory-block-13-*.md`

**Directories:**
- lowercase with hyphens: `memory-blocks/`, `library-sessions/`
- Plural for collections: `agents/`, `prompts/`, `tools/`

**Variables (in prompts):**
- `$variable_name` prefix: `$title`, `$name`, `$description`, `$content`

## Frontmatter Schema

**Required Fields:**
```yaml
---
title: document-name
type: prompt|note|user|index|research|guide
---
```

**Common Optional Fields:**
```yaml
permalink: path/to/document
tags: [tag1, tag2, tag3]
category: lore|persona|tool|workflow|system
categories: [category1, category2]
date: YYYY-MM-DD
status: complete|in-progress
generated_at: YYYY-MM-DDTHH:MM:SSZ
symlink: relative/path
```

**Prompt-Specific:**
```yaml
type: prompt
category: lore|persona
use_tools: fs
```

**Agent Documents:**
```yaml
type: note
permalink: agents/agent-name/category
categories:
  - agents
  - agent-name
tags:
  - skogai
  - agent-name
```

## Prompt Structure

**Standard Template:**
```markdown
---
title: prompt-name
type: prompt
category: category
tags: [relevant, tags]
---

# Objective
[Clear, concise description]

# Inputs
- `$variable` - description (e.g., "example")

# Expected Output
[Specific format requirements]

# Prompt
[Template with CRITICAL RULES]

CORRECT EXAMPLES:
[2-3 examples]

BEGIN [ACTION] NOW:
```

**Critical Rules Pattern:**
```
CRITICAL RULES - READ CAREFULLY:
1. Write ONLY the content - NO meta-commentary
2. DO NOT write: "I will", "Let me", "Here is"
3. START IMMEDIATELY with output
```

## Reference Conventions

**@-notation (SkogAI paths):**
- `@agents/prompts/lore/entry-creation.md`
- `@lore/` - Lore system
- `@knowledge/` - Knowledge base
- `@context/` - Session management

**Variable Substitution:**
- In prompts: `$title`, `$name`, `$entry_count`
- Format: `$lowercase_with_underscores`

**Placeholder Tags:**
- `[$prompt:claude-placeholder-approach]` - Reference to prompt
- `[$DEPRECATED:skogix:TODO:message]` - Deprecation marker
- `[@tag:message]` - Inline note

**Cross-References:**
- Relative markdown links: `[Title](./path/to/file.md)`
- Permalink references: Use `permalink` from frontmatter

## Writing Style

**Prompts:**
- Direct, imperative instructions
- CAPS for critical rules
- Examples provided
- No meta-commentary in output specifications

**Agent Profiles:**
- Philosophical/narrative tone
- Bold headers for sections
- Quoted insights integrated throughout
- Present tense with reflective voice

**Memory Blocks:**
- Long-form narrative (multiple paragraphs)
- Archaeological/exploratory metaphors
- Present tense with reflective tone

**Documentation:**
- Technical but accessible
- Code blocks for examples
- Tables for quick reference

## Tags and Categories

**Standard Tags:**
- Document type: `prompt`, `note`, `user`, `guide`
- Domain: `persona`, `lore`, `tool`, `skogai`, `agents`
- Content: `generation`, `analysis`, `extraction`, `journal`
- Agent: `claude`, `dot`, `goose`

**Categories Array:**
- Used in agent documents for hierarchical classification
- Format: `[parent, child]` e.g., `[agents, claude]`

## Special Conventions

**CLAUDE.md Files:**
- Per-directory AI instructions
- May contain claude-mem auto-generated sections
- Should define directory-specific context

**README.md Files:**
- Directory index and overview
- Quick reference tables
- Navigation guidance
