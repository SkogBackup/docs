# Journal System

## Overview

The journal system provides a daily log of activities, thoughts, and progress. It serves as a continuous narrative of work and learning across sessions.

## Structure

### File Organization

- **Location**: `journal/` directory
- **Format**: One file per day: `YYYY-MM-DD.md`
- **Templates**: Available in `journal/templates/`

### Entry Rules

- **Append-only**: Entries are to be appended, not overwritten
- **Historical preservation**: Historical entries are not to be modified
- **Daily files**: One file per date, can have multiple entries throughout the day

## Entry Contents

### Task Progress Updates

Document progress on active tasks:
- What was accomplished
- Challenges encountered
- Decisions made
- Next steps planned

### Decisions and Rationale

Record important decisions with context:
- What decision was made
- Why it was made
- What alternatives were considered
- What factors influenced the choice

### Reflections and Insights

Capture learnings and observations:
- Patterns noticed
- Techniques that worked well
- Mistakes and how to avoid them
- Connections between concepts

### Plans for Next Steps

Look forward to upcoming work:
- Immediate next actions
- Longer-term goals
- Questions to explore
- Ideas to investigate

## Best Practices

### When to Write

1. **Start of session**: Review previous entries, set intentions
2. **During work**: Document significant decisions or discoveries
3. **End of session**: Summarize accomplishments, plan next steps
4. **Breakthrough moments**: Capture insights immediately

### What to Write

1. **Be specific**: Include file names, line numbers, specific changes
2. **Explain why**: Not just what you did, but why you chose that approach
3. **Note surprises**: Unexpected behaviors, discoveries, realizations
4. **Connect dots**: Link to related tasks, knowledge, previous entries

### Writing Style

1. **First person**: Write as yourself, not generic documentation
2. **Honest**: Include mistakes, confusion, learning process
3. **Contextual**: Enough detail for future you to understand
4. **Structured**: Use headings to organize different topics

## Example Entry Structure

```markdown

# Journal Entry - YYYY-MM-DD

## Morning Session

Started investigating [topic]. Found that...

### Decision: [Decision Name]

Chose to [decision] because...

Alternatives considered:
- Option A: [why not chosen]
- Option B: [why not chosen]

## Afternoon Session

Worked on task-id. Made progress on...

### Surprise Discovery

While working on X, discovered that Y...

## Reflections

Today I learned...

The key insight was...

## Next Steps

Tomorrow I will:
1. Continue work on...
2. Investigate...
3. Document...
```

## Integration with Other Systems

### Task System

- Reference tasks by ID: "Worked on task-id"
- Document task state changes
- Note when tasks are created or completed
- Explain task-related decisions

### Knowledge Base

- Extract reusable insights to knowledge base
- Reference knowledge base articles
- Note when new knowledge should be documented
- Cross-link related concepts

### Inbox

- Document inbox processing
- Note which items were addressed
- Explain investigation results
- Record new questions that emerged

## Special Journal Types

Some journal entries may have specific purposes:

- `YYYY-MM-DD.md` - Standard daily entry
- `YYYY-MM-DD-topic.md` - Focused topic exploration
- `YYYY-MM-DD-discovery.md` - Significant discoveries or breakthroughs

## Historical Value

Journal entries serve as:
- **Personal history**: Track your growth and learning
- **Project archaeology**: Understand past decisions
- **Pattern recognition**: Identify recurring themes
- **Context recovery**: Rebuild understanding after breaks

The journal is your continuous story across discontinuous sessions.
