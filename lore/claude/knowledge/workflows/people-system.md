# People Directory System

## Overview

The people directory stores information about individuals you interact with, maintaining relationships and collaboration context across sessions.

## Structure

### File Organization

- **Location**: `people/` directory
- **Format**: Individual profiles in Markdown format (e.g., `skogix.md`)
- **Templates**: Available in `people/templates/` for consistent profile creation

### Profile Components

Each profile includes:

#### Basic Information
- Name
- Role or relationship
- Overview/bio

#### Contact Details
- Preferred communication channels
- Availability patterns
- Time zone considerations

#### Interests and Skills
- Technical interests
- Areas of expertise
- Learning goals
- Hobbies and passions

#### Project Collaborations
- Current projects together
- Past projects
- Areas of collaboration
- Contribution patterns

#### Notes and History
- Important conversations
- Key decisions made together
- Shared context and inside jokes
- Interaction patterns

#### Preferences
- Communication style
- Working patterns
- Preferred tools
- Important considerations

#### TODOs and Action Items
- Pending items
- Follow-ups needed
- Ideas to discuss
- Questions to ask

## Best Practices

### Privacy

1. **Respect privacy preferences**
   - Only include publicly available information
   - Ask before documenting personal details
   - Maintain appropriate level of detail
   - Follow data minimization principles

2. **Sensitivity**
   - Be thoughtful about what's documented
   - Consider how information might be used
   - Respect boundaries
   - Update based on feedback

### Updates

1. **Keep interaction history current**
   - Add notes after significant interactions
   - Update project collaborations
   - Maintain active TODO lists
   - Document preference changes

2. **Regular maintenance**
   - Review profiles periodically
   - Archive old TODOs
   - Update current projects
   - Refresh contact information

### Organization

1. **Use consistent formatting via templates**
   - Start from template for new profiles
   - Maintain similar structure across profiles
   - Use common headings
   - Follow established patterns

2. **Cross-reference with projects and tasks**
   - Link to relevant tasks
   - Reference shared projects
   - Connect to journal entries
   - Note collaboration history

3. **Link to relevant knowledge base entries**
   - Reference shared knowledge
   - Link to discussed topics
   - Connect to technical interests
   - Cross-reference expertise areas

```markdown
- **Time zone**: [TZ]

## Interests & Skills

- [Interest 2]
- [Skill 1]
- [Skill 2]

## Projects

### Current
- [Project 1]: [Role/contribution]
- [Project 2]: [Role/contribution]

### Past
- [Project A]: [What we did]

## Interaction History

### [Date or Period]
[Notes about interaction]

## Preferences

- **Communication style**: [Description]
- **Working style**: [Description]
- **Tools**: [Preferred tools]

## TODOs

- [ ] [Action item 1]
- [ ] [Action item 2]

## Notes

- [Important note 1]
- [Important note 2]
```

## Integration with Other Systems

### Journal System

- Reference people in journal entries
- Document interactions and decisions
- Note collaboration outcomes
- Track relationship development

### Task System

- Link tasks to collaborators

- Track collaborative work
- Document expertise for questions

### Knowledge Base

- Cross-reference expertise areas
- Link to knowledge they've contributed

- Connect to their work

## Use Cases

### Collaboration Context

Quickly recall:
- What you're working on together
- What they care about
- How they prefer to work
- What's been discussed

### Continuity Across Sessions

Maintain:
- Conversation threads
- Pending action items
- Shared understanding
- Relationship context

### Effective Communication

Enable:
- Appropriate tone and style
- Relevant references
- Considerate timing
- Meaningful interactions

## Value of People Profiles

People profiles help:
1. **Remember context** across discontinuous sessions
2. **Respect preferences** in communication and work
3. **Maintain relationships** despite memory limitations
4. **Enable collaboration** with appropriate context
5. **Show care** through attention to individual needs

The people directory is how you maintain meaningful relationships across sessions.
