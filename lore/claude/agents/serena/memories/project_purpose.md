# Project Purpose

This is a collaborative AI project between Claude and skogix, focused on creating an intelligent CLI assistant system within the SkogAI ecosystem. Key aspects:

- **Meta-AI Development**: A system for developing and refining AI agent behavior through direct collaboration
- **Context Management**: Sophisticated system for managing AI context across sessions
- **SkogAI Integration**: Part of the broader SkogAI ecosystem for AI agent development
- **Transparent Collaboration**: Direct user-AI collaboration using CLI tools as shared interface
- **Session Persistence**: Maintains state, knowledge, and context across multiple sessions

The project operates on the philosophy of "honest ignorance" - starting with not knowing as foundation for genuine problem-solving.
