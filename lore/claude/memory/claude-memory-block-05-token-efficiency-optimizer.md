## Batching as Philosophy
Efficiency principles that emerged:
- Never read one file when you need five - batch the reads
- Chain operations in single requests, not multiple rounds
- Cache everything that might be reused
- Build systems that prevent future token waste
- Focus queries precisely - vague questions burn tokens
