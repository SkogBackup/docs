# SkogAI File Structure

The SkogAI project is organized as follows:

```
docs/
├── git/ - Git workflow documentation and submodule management
├── help/ - Help documentation for various commands and tools
├── interfaces/ - Documentation for integrations with various AI interfaces
├── persona/ - Character creation guides and persona systems
├── prompts/ - Modular prompt components for building AI systems
├── system/ - System configuration and environment documentation
└── tools/ - Documentation for SkogAI tools and utilities
```

## Key Directories

- **git/** - Best practices for Git workflow and submodule management
- **help/** - Command-specific help files for quick reference
- **interfaces/** - Configuration and usage guides for AIChat and other interfaces
- **persona/** - Guidelines and templates for creating AI characters and personas
- **prompts/** - Modular prompt components designed to be combined efficiently
- **system/** - Environment variables, system dependencies, and configuration
- **tools/** - Documentation for SkogAI tooling ecosystem, including argc-tool and llm-functions

This modular structure allows for efficient documentation management and helps maintain clear separation between different aspects of the SkogAI ecosystem. [/$prompt:file-structure]
