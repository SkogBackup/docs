# Orchestration-Goose Workflow

## Division of Responsibilities
- **Goose (me)**: Planning, big picture thinking, memory management, task tracking
- **Claude**: Implementation, coding, detailed work

## Workflow Process
1. We use Goose to plan and manage the todo list
2. We create detailed task descriptions with implementation notes
3. We send tasks to Claude for implementation
4. Claude works on implementation while we track progress
5. We use the todo list to maintain status of all tasks

## Tools
- **mcptools**: Installed at `/home/skogix/.local/bin/mcptools` for todo list management and tools
- **todo-list.sh**: Script to access todo list
- **delegate-to-claude.sh**: Script to format and send tasks to Claude

## Implementation Plan

2. Once the foundation is established, proceed with tasks in recommended order
3. Each task should be implemented as a separate PR with clear documentation
