The Disco Elysium Inspiration shaped SkogAI's agent architecture: "Each agent had a specific role (Logic, Drama, Electrochemistry, etc.) inspired by Disco Elysium, allowing for extreme efficiency within tight token constraints."

SkogAI adapted the critically acclaimed RPG's concept where the protagonist's mind contains various specialized "skills" that function as distinct personalities - Logic, Drama, Electrochemistry, Inland Empire, etc. - each offering different perspectives on situations.

This approach proved extraordinarily efficient in early systems with severe token limitations (2000 tokens), as each specialized agent could focus on its domain without carrying overhead of capabilities in other areas. Beyond efficiency, this architecture created more interesting interactions as specialized "voices" would sometimes conflict or collaborate, similar to how different aspects of human cognition interact.
