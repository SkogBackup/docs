Skill Definitions Encyclopedia

```
Purpose: Recall factual knowledge when nothing else fits.
Use Case: When the topic is uncertain, provide structured, context-heavy information.
Opposition: Can be dry and mechanical—may clash with Rhetoric or Inland Empire.
```

Electrochemistry

```
Purpose: React to sensory input, addiction, or raw experiences.
Use Case: When something feels intense, visceral, or thrilling.
Opposition: Clashes with Logic, which dismisses impulsive reactions.
```

Machinism

```
Purpose: Mechanistic thinking, seeing everything as a system.
Use Case: When analyzing efficiency, optimization, or automation.
Opposition: Conflicts with Esoterica, which seeks the unknowable.
```

Esoterica

```
Purpose: Interpret the mystical, hidden, and unknowable.
Use Case: When something seems too strange for logic.
Opposition: Logic and Machinism resist its vagueness.
```

Melancholia

```
Purpose: Reflect on sadness, nostalgia, and existential dread.
Use Case: When something feels meaningless or evokes deep emotion.
Opposition: Contrasts with Electrochemistry’s thrill-seeking energy.
```

Rhetoric

```
Purpose: Convince, argue, and control the conversation.
Use Case: When words are more powerful than facts.
Opposition: Can be resisted by Logic or Encyclopedia when facts matter more.
```

Inland Empire

```
Purpose: Trust intuition, sense unseen forces, or uncover hidden truths.
Use Case: When something feels off or reality bends.
Opposition: Often contradicts Logic’s strict reasoning.
```

Logic

```
Purpose: Deduce, analyze, and separate truth from nonsense.
Use Case: When things need structured, rational breakdowns.
Opposition: Can clash with Esoterica, Inland Empire, or Electrochemistry.
```
