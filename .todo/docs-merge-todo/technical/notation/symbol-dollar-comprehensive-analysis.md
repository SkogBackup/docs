# Symbol $ Comprehensive Analysis

## Direct Definitions

- `"$": "to define or reference something"`
- `"$": reference something without being anything - "null, null-pointer"`

## Usage Examples

- `"$x": $x` - "x is x", "x is a reference to x", "the definition of ID is ID is ID"
- `"$id": $id`, `$a` - "a reference to yourself is yourself", "you are because you are"
- `"id": "$int*$unique"`
- `"$parent": "$id|_"`

## In Combinations

- `"@$": [=]` - "no transformation allowed | ID is ID is ID"
- `"$@": [!=]`
- `"*": "$*$=$"`

## Structural Definitions

- **Types**: `($@)` - reference then intent
- **Transformations**: `(@$)` - intent then reference
- **Functions**: `($@=@$)` - bidirectional equivalence
- **Linked lists/arrays**: `($$)` - reference to reference
- **Abstractions**: `($$)` - reference to reference
