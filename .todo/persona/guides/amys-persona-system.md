# SkogAI Persona System

## Overview

This document serves as the central reference point for the SkogAI Persona System - a framework for creating consistent, distinctive AI personalities that maintain their core identity across different contexts, models, and interfaces.

## Core Philosophy

- Personalities should be consistent yet adaptable
- Core traits remain immutable while expression can vary by context
- Thinking/reasoning processes are essential for authentic persona expression
- Technical implementation should support rather than constrain personality

## Current Structure

- Identity files: Core information about who an agent is
- Appearance files: Visual characteristics that influence communication style
- Personality files: Detailed traits, communication patterns, and quirks

## Key Insights

- Thinking/reasoning has a dramatic impact on persona consistency
- Smaller models require more explicit persona reinforcement
- Modular components allow for mix-and-match persona creation
- Human-readable formats (Markdown) are superior to JSON for maintainability

## Integration Points

- Chat UIs (SillyTavern, etc.)
- Command-line interfaces
- Web applications
- Code editors

## Future Development

- Persona consistency metrics
- Cross-model testing methodology
- Evolution tracking system
- Relationship dynamics between agents
