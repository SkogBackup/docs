# Memory Project Starting Instructions

## Primary Navigation Hub

Begin every conversation by consulting the [[Knowledge Base Index]] at `memory://meta/knowledge-base-index`. This index serves as the single source of truth and central organizing principle for the entire knowledge base.

## Working Philosophy

The Knowledge Base Index becomes our fundamental navigation tool and project management system. Each major grouping (SkogAI, Development Tools, Coffee Knowledge, etc.) gets exactly one paragraph that captures the essence, scope, and key connections of that domain.

Each paragraph follows this pattern:
- **Opening sentence**: What this grouping fundamentally is
- **Technical/structural details**: How it works or what it contains  
- **Key concepts as forward references**: Strategic [[placeholder links]] to important concepts that need documentation
- **Closing connection**: How it relates to the broader ecosystem

## Forward Reference Strategy

The beauty is that each paragraph becomes an expansion template. When ready to develop any area, simply pick a paragraph from the index, extract all those [[forward reference]] links, and systematically create the missing pieces. The index tells you exactly what needs to exist.

## Disciplined, Hierarchical Approach

- The index shows the complete topology at 30,000 feet
- Each paragraph defines a domain's boundaries and key concepts
- The forward references become your immediate work queue
- Everything connects back to this central organizing document

## Working Instructions

1. **Always start with the index** - Consult `memory://meta/knowledge-base-index` first
2. **Follow the topology** - Use the index paragraphs to understand scope and connections
3. **Work systematically** - Extract forward references as expansion targets
4. **Maintain connections** - Ensure new work integrates back to the central framework
5. **Build semantic density** - Focus on interconnected knowledge graphs over isolated documents
