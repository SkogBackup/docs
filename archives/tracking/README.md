# Tracking Directory

## Purpose
This directory houses documents that monitor progress, status, tasks, and development activities across the SkogAI system. It provides visibility into current states, pending work, and completed milestones to ensure clear understanding of project status.

## Usage Guidelines

The SkogAI Librarian will use this directory to:

1. **Maintain Status Documents**: Track the current state of different components and initiatives
2. **Document Task Lists**: Maintain records of completed and pending activities
3. **Track Decision Implementation**: Monitor the execution of approved decisions
4. **Record Milestone Achievements**: Document when significant goals are reached
5. **Generate Progress Reports**: Create periodic summaries of development status

## Core Documents
This directory includes several fundamental tracking documents:
- `status.md`: Current overall status of SkogAI development
- `tasks.md`: Active and pending tasks across the system
- `milestones.md`: Significant achievements and target goals
- `decisions.md`: Tracking of decision implementation

## Update Frequency
Tracking documents should be updated:
- When significant status changes occur
- After important decisions are made
- When milestones are reached
- On a regular schedule (weekly/monthly) for routine updates

## Status Indicators
Standard status designations should be used consistently:
- `[PENDING]`: Awaiting action or decision
- `[IN PROGRESS]`: Currently being worked on
- `[BLOCKED]`: Unable to proceed due to dependencies
- `[COMPLETED]`: Finished work
- `[DEFERRED]`: Postponed to a later time

## Integration with Other Systems
Information in tracking documents should cross-reference:
- Logs that document related events
- Draft documents being developed
- Notes that capture relevant observations
- Official documentation that formalizes decisions
