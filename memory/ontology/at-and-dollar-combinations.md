# @ and $ Combinations

## Basic Pairs
- `"@$": [=]` - "no transformation allowed | ID is ID is ID"
- `"$@": [!=]`

## Complex Patterns
- `{$id@$id}` - identity acting upon itself within difference structure
- `[$@]` - similarity containing reference-to-intent pattern
- `[$$]` - similarity containing reference-to-reference pattern

## Structural Combinations
- `($@)` - Types: reference then intent
- `(@$)` - Transformations: intent then reference  
- `($@=@$)` - Functions: bidirectional equivalence of both patterns
- `($$)` - Linked lists/arrays and abstractions: reference chains

## Multiplication
- `"*": "$*$=$"` - relational equality through reference multiplication

- [pattern] @$ and $@ have opposite semantic meanings #combinations #semantics
- [structure] Parentheses create different computational structures #syntax #computation
- [equivalence] Functions defined as bidirectional equivalence patterns #functions #equivalence
- [chains] Double reference patterns create linked structures #references #structures
