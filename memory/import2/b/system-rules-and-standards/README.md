# System Rules and Standards

This directory contains the consolidated documentation for all system rules, standards, and guidelines for the SkogAI Memory system. The content has been organized into logical categories to make navigation easier.

## Category Structure

1. **File Naming and Structure** (01-file-naming-and-structure.md)
   - Naming conventions, folder organization, path standards

2. **Document Formatting** (02-document-formatting.md)
   - Markdown usage, content organization, formatting guidelines

3. **Semantic Elements** (03-semantic-elements.md)
   - Observations, relations, categories, tags, semantic markup

4. **Knowledge Graph Practices** (04-knowledge-graph-practices.md)
   - Connection strategies, linking patterns, network building

5. **Automation and Enforcement** (05-automation-and-enforcement.md)
   - Quality control, enforcement scripts, compliance workflows

6. **System Architecture** (06-system-architecture.md)
   - URIs, resource types, system components, integration

## Merging Process

These files represent a consolidation framework for the ~19 individual files related to system rules and standards from the original directory. Each category file should:

1. Combine all related information from source files
2. Eliminate redundancy while maintaining comprehensive coverage
3. Present information in a consistent, organized format
4. Include appropriate observations and relations sections
