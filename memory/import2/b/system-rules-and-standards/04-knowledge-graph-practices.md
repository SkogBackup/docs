# Knowledge Graph Best Practices

## Summary
This category provides guidelines for creating an effective, interconnected knowledge graph through deliberate linking patterns, connection density, and relationship management strategies.

## Topics Included
- Connection density recommendations
- Bidirectional linking strategies
- Forward reference handling
- Knowledge network growth patterns
- Semantic relationship design

## Expected Source Files
- Knowledge-graph documents
- Connection-related guides
- Linking-strategy files
- Graph-structure recommendations

## Key Principles
- A densely connected knowledge graph provides more value than isolated notes
- Create bidirectional links between related documents where appropriate
- Forward references (to non-existent notes) are supported and resolved when created
- Aim for 3-5 observations and 2-3 relations per document
- Use specific relation types rather than generic connections
