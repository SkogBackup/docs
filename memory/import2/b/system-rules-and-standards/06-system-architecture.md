# System Architecture

## Summary
This category documents the underlying architectural design of the SkogAI Memory system, including URI structures, resource types, system components, and how these elements integrate to create a cohesive knowledge management ecosystem.

## Topics Included
- Memory URI structure and protocol
- Resource type taxonomy and usage
- System component relationships
- Tool integration patterns
- Architecture visualizations

## Expected Source Files
- URI-related documents
- System-architecture guides
- Component-relationship diagrams
- Resource-type documentation

## Key Principles
- Memory URIs follow `memory://[resource-type]/[identifier]` format
- Resource types include: note, entity, conversation, content
- The system is designed for interoperability with CLI tools
- Architecture enables both human and machine interaction
- System components are designed to be modular yet integrated
