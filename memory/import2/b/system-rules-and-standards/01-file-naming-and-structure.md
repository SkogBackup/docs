# File Naming and Structure

## Summary
This category covers all standards related to how files are named and organized in the SkogAI Memory system, ensuring consistency, searchability, and compatibility across different environments.

## Topics Included
- Kebab-case naming convention (lowercase-with-hyphens)
- Special file exceptions (README.md, RULES.md, TODO.md)
- Directory hierarchies and folder organization
- Path conventions and avoiding redundancy
- File extensions and type conventions

## Expected Source Files
- RULES-prompt.md / RULES-evaluation.md
- Format-prompt.md / Format-evaluation.md
- file-structure-related documents
- naming-convention documents

## Key Principles
- All filenames use lowercase with hyphens for word separation
- Special system files may use uppercase by convention
- Filenames should be descriptive but concise
- Folder structure should convey context so filenames can be simpler
- Avoid redundancy between paths and filenames
