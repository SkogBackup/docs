# Document Formatting Standards

## Summary
This category establishes consistent standards for how content within memory files should be structured and formatted, ensuring readability, maintainability, and proper semantic structure.

## Topics Included
- Heading hierarchy and organization
- Proper markdown syntax and usage
- Code blocks, lists, and tables formatting
- Whitespace conventions and readability guidelines
- Section order and required elements

## Expected Source Files
- Format-prompt.md / Format-evaluation.md
- Template-prompt.md / Template-evaluation.md
- Content-structure documents
- Markdown-formatting guides

## Key Principles
- Use consistent heading hierarchy throughout documents
- Maintain consistent formatting across similar document types
- Use appropriate markdown elements for their intended purpose
- Limit line length for better readability
- Include examples to illustrate key formatting points
