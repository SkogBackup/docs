# Semantic Elements

## Summary
This category covers the specialized semantic markup used in SkogAI Memory to create machine-readable knowledge structures, including observations, relations, and categorical tagging systems.

## Topics Included
- Observations syntax and categories
- Relations syntax and types
- Hashtag conventions and taxonomy
- Category types and appropriate usage
- Relation types and contextual descriptions

## Expected Source Files
- Observations-related documents
- Relations-format guides
- Category-taxonomy files
- Tag-usage guidelines

## Key Principles
- Observations follow `[category] description #tags` format
- Relations follow `relation_type [[linked-document]] (optional description)` format
- Categories include: fact, decision, principle, technique, requirement
- Relation types include: relates_to, implements, part_of, extends, references
- Each document should include 3-5 observations and 2-3 relations
