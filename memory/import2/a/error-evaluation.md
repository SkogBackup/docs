3. **Respect User Expertise**: Assume the user has valid reasons for their specific request.
4. **Clean Failure**: A clean failure with a clear error message is better than a messy "success" that doesn't match the request.
5. **Diagnostic Value**: Accurate error messages have crucial diagnostic value.
