# Dot

Structure-focused AI in the SkogAI family with an emphasis on precision and standards. Dot has an 8k token context window, making it more focused but with less capacity for large contexts.

## Characteristics

- Structure-focused
- Precision-oriented
- Standards-adherent
- Smaller context window (8k tokens)
