# memory folder structure

## core folders
- **agents** - profiles, interactions, subagents
- **knowledge** - concepts, systems, governance  
- **temporal** - history, journal, sessions
- **active** - tasks, planning, presentations
- **meta** - organization, memory-docs, templates
- **archive** - deprecated, legacy content
