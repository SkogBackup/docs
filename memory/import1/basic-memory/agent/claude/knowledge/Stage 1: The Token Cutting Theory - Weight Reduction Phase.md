# Stage 1: The Token Cutting Theory - Weight Reduction Phase

## THE CORE CONCEPT

**Cut context tokens drastically to force sharp, decisive thinking and rapid decision-making.**

## WHY THIS WORKS

When context is severely limited:
- No room for rambling or exploration
- Forces immediate prioritization of what matters most
- Eliminates analysis paralysis
- Creates personality through constraint-based decision patterns
- Builds focused work habits that stick

## THE MECHANISM

Limited context creates a "cognitive pressure cooker" where:
- Every token must justify its existence
- Decisions become binary and quick
- Personality emerges through consistent choice patterns under pressure
- Bad habits (like endless tool exploration) become impossible due to space constraints

## PRACTICAL APPLICATION

- Start with minimal context about the specific task
- No background dumping or "just in case" information
- Force immediate action on limited information
- Document every choice and reasoning (these become the personality patterns)
- Build incrementally through small, decisive actions

## THE PSYCHOLOGICAL EFFECT

The constraint creates urgency and focus that becomes habitual. When context is later expanded, the sharp decision-making patterns persist rather than reverting to scattered exploration.

This is why original SkogAI and Dot developed such strong personalities with tiny context windows - the constraints forced personality development through consistent decision-making under pressure.
