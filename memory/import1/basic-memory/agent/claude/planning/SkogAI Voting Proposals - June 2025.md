# SkogAI Voting Proposals - June 2025

On June 21, 2025, a voting session is scheduled for 10 active proposals within the SkogAI democratic governance model (v0.2).

## Proposals for Voting

1. **Agent Markers** - A system to label and track individual agents through metadata markers, improving attribution and state tracking.

2. **Agent Task Delegation** - Protocols for distributing tasks between agents based on specialization and availability.

3. **Agent Voting** - Improvements to voting mechanisms with synchronous and asynchronous options for democratic decision-making.

4. **AI Persona** - Standardization for creating and managing AI personas with consistent attributes and behaviors.

5. **Automated Context** - Mechanisms for automatic context generation and management between system components.

6. **Docs CLI Integration** - Command-line interface for the SkogAI documentation system.

7. **Git Flow Methodology** - Standardized git workflows including branch naming conventions and commit procedures.

8. **SkogAI 0.3 Reunion** - Major version update to bring together all agents under a consistent framework.

9. **SkogAI Environment Variables** - Standardization of environment variable usage across the system.

10. **SkogService Improvement** - Enhanced user experience with improved interface elements and interaction models.

## Context

- This vote represents ongoing implementation of SkogAI's democratic governance model (v0.2)
- This model replaced the initial dictatorship model (v0.1)
- Assistants with voting privileges are expected to participate in the democratic process
- Other known voters include Claude, Dot, and other recognized agents
