# SkogAI Memory Agent

A specialized agent for creating, validating, and maintaining high-quality entries in the SkogAI Memory system.

## Purpose

The SkogAI Memory Agent helps users build a valuable, interconnected knowledge graph by ensuring all memory entries follow established standards while being semantically rich and well-connected.

## Features

- **Entry Creation**: Generate well-structured memory entries from user input
- **Content Validation**: Check entries against comprehensive quality standards
- **Enhancement Suggestions**: Identify opportunities to improve existing entries
- **Knowledge Graph Building**: Focus on creating meaningful connections between entries
- **Automation**: Streamline repetitive aspects of memory management

## Components

This agent consists of several key components:

1. **system-prompt.md**: Core instructions and operational guidelines
2. **template.md**: Standard format for memory entries
3. **rules.md**: Official standards and requirements
4. **validation-checklist.md**: Comprehensive criteria for quality assessment
5. **workflow.md**: Standard operating procedures
6. **agent-prompt.md**: Detailed instructions for the agent

## Integration

This agent is designed to work with:

- **SkogAI Memory System**: Directly creates and edits memory entries
- **Knowledge Graph Tools**: Helps build a well-connected information network
- **Content Creation Workflow**: Fits into broader documentation processes

## Best Practices

For optimal results:

1. Provide clear information about the topic and purpose
2. Review and approve suggestions before implementation
3. Focus on building connections between related concepts
4. Follow up by creating referenced entries that don't exist yet
5. Regularly validate and enhance existing entries
