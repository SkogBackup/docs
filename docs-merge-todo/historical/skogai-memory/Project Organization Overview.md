# SkogAI Knowledge Base: Project Organization Overview

## 🚀 **Active Development Projects**

### **1. SkogContext Project** *(Context Generation Framework)*
**Status:** Active Development  
**Focus:** Modular AI context generation system using argc CLI framework  
**Documentation:** 8+ documents

**Key Components:**
- `argc-cli-framework` - CLI framework with AI-safe script execution
- `architecture-static-vs-agent-tools-pattern` - Design patterns for static vs agent-specific tools
- `learning-session-from-monolithic-to-modular-context-generation` - Evolution from monolithic to modular approach
- Multiple Claude integration documents covering architecture, understanding, and implementation

**Purpose:** Replace legacy SkogAI monolithic context system with modular framework that provides infrastructure for AI agents to generate exactly the contextual information they need.

### **2. Arch Linux Automation Project** *(Ansible Infrastructure)*
**Status:** Planning/Research Phase  
**Focus:** i3-based Arch Linux desktop automation using Ansible  
**Documentation:** 15+ documents

**Key Components:**
- Comprehensive research into 25+ existing Ansible Arch repositories
- Custom project structure designed for i3 window manager
- Role-based modular design (base system, i3 WM, development tools)
- Security-focused with AUR helper integration

**Purpose:** Automated setup and maintenance of Arch Linux development environments.

### **4. Cloudflare Production Development** *(Cloud Infrastructure)*
**Status:** Planning Phase  
**Focus:** Production-ready systems on Cloudflare platform using MCP access  
**Documentation:** 2+ planning documents

**Key Components:**
- Transition from exploration to production development
- AutoRAG and Developer Platform integration
- Collaborative development approach with Claude

**Purpose:** Build production-ready cloud systems leveraging Cloudflare's platform capabilities.
