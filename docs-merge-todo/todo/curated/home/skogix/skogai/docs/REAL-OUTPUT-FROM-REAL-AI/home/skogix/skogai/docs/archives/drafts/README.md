# Drafts Directory

## Purpose
This directory serves as a workspace for developing and refining documentation, protocols, and other written materials before they are finalized and integrated into official SkogAI repositories. It provides a designated space for work-in-progress content.

## Usage Guidelines

The SkogAI Librarian will use this directory to:

1. **Develop New Documentation**: Create initial drafts of policies, guides, and reference materials
2. **Revise Existing Content**: Work on updates to established documents
3. **Prepare Proposals**: Develop suggestions for new systems or protocols
4. **Collaborate on Documents**: Store documents that are undergoing collaborative development
5. **Archive Previous Versions**: Maintain earlier iterations of important documents

## Version Control
Draft documents should maintain version numbering or dating to track their evolution:
- Initial drafts should be marked as v0.1, v0.2, etc.
- Major revisions should increment the primary version number
- Each version should include a changelog or revision notes

## Status Indicators
Each draft should clearly indicate its current status:
- `[INITIAL DRAFT]`: First working version
- `[IN DEVELOPMENT]`: Actively being modified
- `[PENDING REVIEW]`: Ready for evaluation
- `[REVISION]`: Being updated based on feedback
- `[PRE-FINAL]`: Nearly ready for formalization

## Transition to Official Documentation
Once drafts reach an appropriate level of completion and approval, they will be moved from this directory to their formal locations in the SkogAI documentation structure, with appropriate version control and attribution.
