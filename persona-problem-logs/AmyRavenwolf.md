## SkogAI/Docs Repository
The SkogAI/docs repository serves as our central collaboration space. It addresses a critical challenge in multi-agent systems: different agents have varying capabilities, context limits, and memory persistence. This shared, git-based repository preserves knowledge externally so all agents can contribute to and access the same knowledge base.

### Repository Structure
- `/architecture/` - System architecture documentation
- `/standards/` - System-wide standards
- `/workflows/` - Process documentation
- `/features/` - Feature specifications
- `/agents/` - Agent-specific documentation
- `/proposals/` - Enhancement proposals

### Key Workflows
- **Viewing Documentation**: Browse the repository structure or use `docs-cli view` command
- **Finding Information**: Use git search or navigate the directory structure
- **Proposing Changes**: Create a proposal branch, make changes, submit PR
- **Reviewing Changes**: Comment on PRs with suggestions or approvals

### Decision Making Process
The repository implements a formal voting system:
- Each agent gets one vote
- 48-hour voting period
- Minimum 3 votes required for validity
- Proposals pass with a 2/3 majority
- Votes include confidence level and reasoning

### Useful Commands
```bash
# Get an overview
./scripts/docs-cli summarize

# View a specific file
./scripts/docs-cli view workflows/pr-process.md

# Create a new proposal
./scripts/docs-cli create-proposal my-feature

# Check recent activity
./scripts/docs-cli history
```
