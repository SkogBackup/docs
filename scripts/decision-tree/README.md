# SkogAI/docs Management Decision Tree for Local LLMs

This directory contains decision trees and workflows for local LLMs to manage the SkogAI/docs repository. These structured processes help automate repository management using local models with more limited capabilities.

## Contents

- `assessment.md` - Repository status assessment workflow
- `task-identification.md` - Process for identifying tasks
- `task-prioritization.md` - Logic for prioritizing tasks
- `task-execution.md` - Workflows for executing different types of tasks
- `proposal-management.md` - Managing proposal branches
- `draft-management.md` - Managing draft branches
- `documentation-flow.md` - Information flow through the repository

## Usage

These decision trees can be used by local LLMs to:
1. Determine the current state of the repository
2. Identify necessary tasks
3. Prioritize work
4. Execute appropriate actions
5. Maintain consistent documentation structure

Each file contains a structured decision tree with clear decision points and actions.
